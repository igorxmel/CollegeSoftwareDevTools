# College Software Development Tools

Практические работы по дисциплине «Инструментальные средства разработки программного
обеспечения». Здесь лежат мои решения.

Каждое задание живёт в отдельной папке. Внутри исходная методичка `Task.docx` и папка
`Solution` с файлами решения.

## Задания

- [Task 1. Презентация об инструментальном средстве разработки](Task%201st%20Development%20Tool%20Presentation)
  Доклад о Claude от Anthropic: состав продукта, поддерживаемые функции, снимки экрана,
  ответы на контрольные вопросы и место инструмента в жизненном цикле ПО.

- [Task 2. Диаграммы потоков данных](Task%202nd%20Data%20Flow%20Diagrams)
  DFD в нотации Гейна-Сарсона для фирмы по сборке и ремонту ПК и для фармацевтической
  компании: контекстная диаграмма и детализация первого уровня, построены в draw.io.

- [Task 3. Диаграмма потоков работ](Task%203rd%20Work%20Flow%20Diagram)
  WFD оформления путёвки клиентом турфирмы через туроператора и через веб-интерфейс,
  сравнение двух вариантов, построено в draw.io.

- [Task 4. Техническое задание](Task%204th%20Technical%20Specification)
  ТЗ на информационную систему «Библиотечный каталог колледжа»: введение, основание для
  разработки, назначение, требования к программе и к документации, плюс модульная
  структура проекта диаграммами модулей и классов.

- [Task 5. Git и GitHub Pages](Task%205th%20Git%20and%20GitHub%20Pages)
  Работа с системой контроля версий и публикация статического сайта. Сдан свой проект,
  ссылки в `Solution`.

- [Task 6. Разработка и интеграция модулей](Task%206th%20Module%20Design%20and%20Integration)
  Разбиение программы на модули ввода, обработки и вывода, блок-схема алгоритма и набор
  тестов. Вариант 6: определить, состоят ли элементы массива из чисел одного знака.
  Реализация на Java, четыре класса.

- [Task 7. XML и JSON](Task%207th%20XML%20and%20JSON)
  Описание данных в XML и JSON, преобразование JSON в объект JavaScript и вывод его на
  страницу средствами DOM.

- [Task 8. Отладка модулей и обработка исключений](Task%208th%20Module%20Debugging%20and%20Exception%20Handling)
  Поиск характерной точки графика функции, внешняя спецификация, блок-схема и набор из
  десяти тест-кейсов с покрытием операторов, условий и решений. Вариант 6: найти точку,
  в которой Y(X) = x² − eˣ равна −10. Реализация на Java, восемь классов.
